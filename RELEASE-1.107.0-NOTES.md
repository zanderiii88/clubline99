# CLUBLINE 99 v1.107.0 - clearer section-by-section stadium projects

The existing stadium designer already supports selecting and building individual sections. This round improves the planning and confirmation stage:

- An itemised quote lists each changed section, its stand/roof/rear/finish/frontage changes and exact cost. The itemised total matches the existing construction quote.
- Cash after payment is compared with four weekly payrolls. A shortfall is advisory, not a new spending restriction. Other running costs and uncertain gate income still matter; this is not a cash-flow forecast.
- The confirmation screen lists the specific reasons preventing a start: site restrictions, capacity limits, insufficient funds, overlapping stadium bookings, an active project or no selected changes.
- The review minimum now matches the existing confirmation rule for grounds originally below 10,000 capacity.
- Neutral-venue fixtures are excluded from the home-ground disruption list. Away fixtures and matches on/after the reopening date remain excluded. Home friendlies still count where applicable.

Construction prices, duration, payment rules and the one-project-at-a-time system remain. Money is charged on confirmation; affected sections close until completion. This is the planning stage of the stadium-development work, not a new construction queue.
