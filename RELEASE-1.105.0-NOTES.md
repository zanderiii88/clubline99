# CLUBLINE 99 v1.105.0 - rivalry and manager history

Pre-match press encounters now retain a career-context snapshot: recorded competitive meetings against that club, wins/draws/losses, the last score (your club first), and the last retained substantive exchange with the opposing manager. Penalty outcomes count as tie wins/losses; the displayed score remains the recorded match score. Friendlies, future results, other clubs' results and duplicate archived/current reports are excluded.

Club history and manager history are separate. Personal exchanges follow the manager's stable identity through a job change; a replacement manager does not inherit those remarks. When a manager comments after your previous challenge, their quote can acknowledge it. Reporter-led questions also show the context snapshot. Existing response choices, cooldowns, no-comment option, result follow-ups and capped morale/goodwill effects remain. History creates no additional automatic match-strength effect.

Only retained managed-career data is used, not historical real-world head-to-head results. Incomplete older careers can have gaps. Personal context uses retained substantive exchanges (the current media log holds up to 80 entries); no-comment responses are not described as substantive exchanges. The snapshot remains fixed when reviewing a saved encounter. Older entries without context remain readable; new context is validated during save/backup checks.

Verification: pure history cases cover archive/current duplication, friendlies, future and foreign reports, penalty results, manager identity and read-only advice. Manager/media and post-match suites pass. In both management modes, application checks cover context rendering, compressed save/reload, portable backup, invalid context rejection, deferred questions, no duplicate effects, legacy saves and real match/result feedback. Source integrity checks pass, including syntax, five divisions, stadiums/kits and 202 exact import/cache URLs. Database files are unchanged.

No new full-season or browser layout run was performed for this release. The four-season evidence in v1.104 remains historical. Physical Android and production offline replacement remain untested.
