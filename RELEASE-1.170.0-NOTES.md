# CLUBLINE 99 v1.170.0

- Back during a pitch match pauses play, saves the current state and opens the regular leave-match prompt above the pitch. Return to match restores the previous playback state.
- Career restore checks the pitch fixture, players, ball, score and viewing settings before opening a saved match. Earlier pitch saves can still load with default viewing settings.
- A failed save keeps the match open when choosing Main menu from the leave prompt. An unreadable local save shows a message on the title screen.

Apply the cumulative patch over v1.162 or later, including the surroundings files.
