# CLUBLINE 99 v1.160.0

Shared menu and action buttons use raised navy faces, bold lettering and recessed press feedback. Gold marks the main match, calendar and stadium confirmation actions. On the start screen, gold follows Continue when a career is saved and New Career on first launch. Mobile menu actions have 48px minimum height, with 56px for primary buttons. Stadium cycling arrows have at least 48px of width. Narrow portrait menus put the developer shortcut on its own row.
