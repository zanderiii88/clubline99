# CLUBLINE 99 v1.161.0

The mobile title menu now has clipped metallic rims, a deep navy face, bold slanted labels and a two-column layout at narrow portrait widths. Menu buttons retain their touch targets.

Between highlights the match lab displays team names, match possession percentages and a possession bar, alongside shots, shots on target and corners from the same simulation.

Options and the bottom of the developer match page offer Keep screen on while playing. The preference applies to the visible game and match lab on browsers that support screen wake lock. The app requests the lock again when you return.
