# CLUBLINE 99 v1.111.0 - stadium blueprint and phased building batch

## Complete planning flow
Save one target blueprint from the stadium designer, compare the full project with North/South/East/West/corner phases, review a phase, complete its works and restore the blueprint to see what remains. Blueprint save/restore/forget controls are available in the designer in both modes. The target contains section configurations; it does not reserve funds, alter the built ground or start works.

The comparison shows each option's cost, duration, expected opening, capacity during works, capacity after that phase and affected home fixtures. Every estimate starts today from the current ground. Durations and fixture counts cannot be summed to predict a sequential programme. Site, funding, capacity and booking restrictions are rechecked in the existing confirmation flow.

For multi-stand previews, 'Save full blueprint & review [stand] only' preserves the full target and opens confirmation for just that stand. If only one stand remains, use Review whole preview. Confirming pays for that reviewed scope only. The existing one-active-project rule prevents overlapping phases; there is no automatic queue or future payment commitment.

After reopening, restore the saved target to compare it against the updated ground. Completed sections no longer count as unfinished. Restoring replaces the current preview, not the ground. The blueprint remains a fixed target: if you make unrelated later changes, review the restored plan carefully because it may propose reverting them. Saving again replaces the one saved blueprint.

Blueprints are carried in career saves and portable backups with optional-field validation. Older careers have no saved blueprint until you save one. Progress and completed-project history from earlier releases remain available.
