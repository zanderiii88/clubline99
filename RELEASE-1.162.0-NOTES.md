# CLUBLINE 99 v1.162.0

League matchday now offers **Watch on pitch (pilot)** with an available XI in both career modes. It uses the selected starters, bench and formation, with fitness and suspensions drawn from the career. Highlights are the initial view. Edit shape, apply tactical changes and make substitutions from the match screen.

Use **Save & exit** to return to the title and **Continue** to reopen the match paused. Select **Match report** at full time to record the result and player appearances in the career. The pilot uses the existing league table, disciplinary and financial settlement.

The first integration test plays an away fixture, edits a formation, substitutes at half-time and resumes from a save. It checks score orientation, minutes, the league table and duplicate result submission.
