# CLUBLINE 99 — v1.74.0

Complete release: stadium dashboard, player search/free agents, youth call-ups and clearer matches, including Streamlined, In-depth and all earlier usability fixes, all game assets and the five supplied Pixabay music tracks.

## Install

1. Export a career backup from Options & Help before uploading.
2. Extract this ZIP. Upload its contents to the root of your existing GitHub Pages game folder, replacing matching files. `index.html`, `app.js`, `style.css`, `sw.js`, `version.json` and the `assets` and `data` folders belong together.
3. Allow GitHub Pages to finish publishing. Open the game, use Check for Updates and Load update if offered, then reopen it. The title should show v1.74.0.

This ZIP is a full release: no earlier ZIP or separate audio/menu download is needed. Nothing has been deployed automatically. Existing careers use the same save key.

Old generated `assets/audio/menu-*.mp3` files can be deleted from your repository; this release uses only the five supplied music tracks and the advance tick effect.

Choose Streamlined or In-depth when starting a new career. Existing careers retain In-depth; change Management depth in Options & Help to try Streamlined without restarting.

Read RELEASE-1.74.0.md for changes and validation.
