# CLUBLINE 99 - v1.125.0

Retro football management with Streamlined and In-depth modes. This build adds continuous light recorded ambience, button clicks, three calendar simulation choices with result recaps, a compact stadium builder, 40 historical starting managers under the existing names toggle, and richer match passages.

## Install

If you installed v1.121, remove assets/audio/ambience/ and tools/build-ambience.py before uploading game files again. A ZIP extraction cannot delete old files. Playback is disabled regardless.

1. Export a career backup from Options & Help before updating.
2. Use either Clubline-v1.94-onwards-to-v1.125-Update.zip over an existing v1.94-v1.124 installation, or Clubline-1.125.0-Complete.zip for the full game. The update includes every change since v1.94; earlier update ZIPs are not required. The complete ZIP includes all game data and assets.
3. Extract the chosen ZIP into the root of the existing game folder, replacing matching files and retaining subfolders. The files belong directly alongside index.html, not inside an extra parent folder. Keep existing assets/data when using the smaller update.
4. When you choose to publish the files, let GitHub Pages finish, open the game, use Check for Updates and Load update if offered, then reopen it. The main menu should show v1.125.0.

No fresh career is required. Nothing has been published automatically. Existing careers retain their management mode; Options & Help lets you change Management depth without restarting.

Read RELEASE-1.125.0-NOTES.md for changes and verification limits, and ROADMAP.md for priorities.
