# CLUBLINE 99 v1.154.0

## Database lineups in the match lab

Open **Developer · Match test → Tactics and squads → Team strength → Use club ratings**. Database lineups are enabled by default for those fixtures. The lab selects an XI for its 4-4-2 using position ratings, and a five-player bench with a reserve goalkeeper. It uses the game's player names, numbers, attributes and starting fitness and respects the real-names preference. Switch off **Use database lineups** to try the same clubs with fictional squads.

Player ratings blend with the original lab attributes. The lab uses those player ratings in place of the separate club rating gap when database lineups are active, while retaining the chosen venue adjustment. It keeps its existing movement, highlights and substitution rules. This test uses the starting-season database and the lab's 4-4-2 formation. Career squads and saved results continue through the established match view.
