# CLUBLINE 99 v1.109.0 - completed stadium project records

Completed works now leave a record in the Facilities/designer construction area and Streamlined Club workspace, including when no project is active. Each record shows its start if known, scheduled reopening, completion-recorded date, original payment, sections built and capacity before/after when recorded. Section details include the resulting stand, roof, rear, finish and frontage.

Capacity snapshots are captured when a new project starts. Existing in-progress projects can be recorded on completion, but unknown capacity figures remain unavailable. Earlier completed works are not reconstructed from news or the current ground. The latest 200 completed projects are retained.

Recording occurs once as the existing completion process reopens the sections. It does not charge money, create income or change the construction schedule. Repeated completion calls and duplicate history keys do not add another record. History survives season data alongside the career and is validated during local save loading and portable backup imports. Legacy careers without the optional field remain compatible.

Verification: completion/payment once, exact capacity/payment snapshots, duplicate prevention, legacy unknowns and malformed records. Both-mode application checks cover historical rendering, no viewing charge, compressed save/reload, portable backup and invalid history rejection, alongside existing quote/progress tests. Source integrity passes with 208 exact cache/import URLs. Data is unchanged. No new browser layout, full-season, physical Android or production offline upgrade test was performed this release.

Export a backup first. Cumulative update supports v1.94 through v1.108; complete ZIP includes all assets. No fresh career required. Nothing published.
